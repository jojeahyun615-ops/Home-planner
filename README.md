# 재무플래너 — 주거자금 설계 (AFPK 영 플래너 챌린지 2026 선택 제출물)

설계사가 재무계획을 세워 제시하고, 고객이 선택한 뒤 매달 실행을 기록·점검하는 주거자금 설계 앱입니다.
시연용 가상 고객(김하늘)의 데이터가 들어 있습니다. **실제 금융정보를 입력하지 마세요.**

## 여는 방법
- **파일로 열기**: `index.html`을 더블클릭합니다. 서버·로그인·인터넷 연결이 필요 없습니다.
- **웹 주소로 열기**(GitHub Pages 등 https): 홈 화면에 설치할 수 있고, 한 번 연 뒤에는 오프라인에서도 열립니다.
- 처음 열면 고객 홈이 보이고 [둘러보기 시작(약 2분)]이 나옵니다. 상단에서 [설계사 화면 / 고객 화면]을 바꿀 수 있습니다.

## 계산 검증
- 화면: 설계사 화면 → 6 점검 → 계산 검증(정답 테스트 표, 월별 계산표, CSV, 공개 계산 순서)
- 명령: Node 18 이상에서 `node --test tests/`

## 원칙
- 결정론적 월별 계산만 씁니다(확률 표현 없음). 충격 시나리오는 "이 충격이 오면"의 조건부 결과입니다.
- 서버·로그인·외부 AI·외부 API·계좌 연동이 없습니다. 모든 문장은 계산 결과로 만든 규칙 기반 문구입니다.
- 데이터는 이 기기의 브라우저에만 저장됩니다(더보기 → 데이터 관리에서 내보내기·불러오기·초기화).
- 특정 금융상품·회사를 추천하지 않습니다. 정책상품 조건은 확인일 기준이며 가입·신청 전에 공식 기관에서 다시 확인해야 합니다.

## 폴더
- `src/` 계산 엔진과 화면(`src/ui/`), `data/` 시연 고객·정책 데이터, `tests/` 정답 테스트
- `docs/prompt-log.md` 요청·결과 기록, `docs/verification-log.md` AI 비판적 검증 기록
- 제출용 .zip에는 `.claude/` 폴더(개발용 미리보기 설정)를 넣지 않습니다.

## GitHub Pages 배포(팀 공유)

`main` 브랜치에 올리면 GitHub Actions가 **정답 테스트(`node --test tests/`)를 먼저 돌리고, 통과했을 때만** 사이트에 배포합니다(`.github/workflows/pages.yml`). 테스트가 실패하면 배포되지 않아 예전 버전이 그대로 남습니다.

### 처음 한 번
1. github.com에서 새 저장소를 만듭니다(README·.gitignore 추가 없이 빈 저장소로).
   - 무료 계정은 **공개(Public) 저장소**에서만 Pages를 쓸 수 있습니다. 비공개 저장소는 유료 요금제가 필요하고, 그래도 사이트 주소 자체는 누구나 열 수 있습니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. 이 폴더에서 저장소를 연결하고 올립니다.
   ```bash
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   ```
4. 저장소 **Actions** 탭에서 "테스트 후 배포"가 끝나면(1~2분) 사이트 주소가 나옵니다: `https://<계정>.github.io/<저장소>/`
5. 팀원은 **Settings → Collaborators**에서 초대합니다.

### 팀원이 고칠 때
- `main`에 바로 올리면 테스트 통과 후 자동 배포됩니다. 큰 변경은 브랜치를 만들어 Pull Request를 열면 테스트만 먼저 돌아갑니다(배포는 안 함).
- 정답 테스트(`tests/cases.js`)의 기대값은 합의 없이 바꾸지 않습니다(CLAUDE.md 0절 5).

### 데이터는 공유되지 않습니다
- 사이트는 같아도 **입력한 기록·계획은 각자 브라우저에만** 저장됩니다. 서버가 없으므로 팀원이 같은 데이터를 보려면 더보기 → 데이터 관리 → **내보내기(JSON)** 파일을 주고받아 **불러오기** 하세요.
- 공개 주소이므로 실제 금융정보는 넣지 않습니다(시연용 가상 데이터만).
- 배포 후 화면이 예전 그대로면 새로고침 한 번이면 됩니다(오프라인용 캐시는 인터넷이 끊겼을 때만 씁니다).
